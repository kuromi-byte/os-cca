# Raspberry Pi Smart Fan Controller

An automated temperature-based cooling system built using the **Raspberry Pi Pico 2 (RP2350)**.

The system monitors ambient temperature using a temperature sensor and automatically controls a DC fan based on predefined temperature thresholds. It aims to provide efficient cooling while reducing unnecessary fan operation.

### Features
- Real-time temperature monitoring
- Automatic fan control based on temperature
- PWM-based fan speed regulation
- TFT touchscreen interface for displaying temperature and system status
- RTC module for timekeeping
- User controls for system interaction

### Hardware
- Raspberry Pi Pico 2 (RP2350)
- Temperature sensor
- DC fan
- Motor driver
- TFT touchscreen display
- DS3231 RTC module
- Supporting electronic components

### Technologies
- Arduino IDE
- Arduino C++
- Raspberry Pi Pico Arduino Core
